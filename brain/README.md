# brain — the Zig verbs

See `docs/PLAN.md` for scope. This is the conkers cartridge's brain half: a
byte-for-byte port of `mirror/src` (the TypeScript reference) plus the four
verbs on the brain's `verb.dispatch` surface, wired like
`vendor/semantos-core/cartridges/chess/brain`.

| File | Module | Port of |
|---|---|---|
| `derive.zig` | `conkers_derive` | `mirror/src/derive.ts` (genesis hash chain) |
| `cells.zig` | `conkers_cells` | `mirror/src/cells.ts` (six payload layouts, offsets by comptime reflection) |
| `physics.zig` | `conkers_physics` | `mirror/src/physics.ts` (score, impact, previewMatch) |
| `script.zig` | `conkers_script` | `conkerLock()` in `mirror/src/script.ts` (lock bytes only; no signing) |
| `verbs.zig` | `conkers_verbs` | `mirror/src/verbs.ts` (mintPair, verifyGenesis, resolveMatch, transferPair) |
| `walkers.zig` | `conkers_walkers` | the JSON verbs `mint`, `verify_genesis`, `resolve`, `transfer` |
| `boot_spec.zig` | `conkers_boot_spec` | construct / register / destroy for the brain's boot table |
| `vectors_test.zig` | — | every entry of `spec/vectors.json` re-derived and compared |
| `build.zon` | — | the module graph the brain's build reads |

`hash160` uses the cell-engine's `ripemd160.zig` by reference (`conkers_ripemd160`),
and `spec/vectors.json` is embedded as the `conkers_vectors` data module.

## Running the tests

```
brain/test.sh                      # plain `zig test`, each module with its imports
```

The brain's own build is the real run and needs Zig 0.15.2 (its
`minimum_zig_version`); this cartridge lives outside the submodule's
`cartridges/` tree, so pass it as a `-Dcartridge` dir:

```
cd vendor/semantos-core/runtime/semantos-brain
zig build test -Dcartridge=/absolute/path/to/conkers
```

Under Zig 0.16 the vendored brain modules do not compile (`ArrayList` init
changed); `test.sh` then tests against a patched scratch copy and says so.

## Contract with the mirror

`spec/vectors.json` is generated by `pnpm --filter @conkers/mirror vectors` and
holds the DEV issuer's genesis signature, 8 derived conkers, 12 impacts, 3 locks,
2 mints, a 4-turn resolve and a transfer, all as the mirror's bytes. Both
`mirror/src/__tests__/vectors.test.ts` and `brain/vectors_test.zig` check every
entry, so a change in either tier shows up as a failure in the other. Change the
reference, regenerate, then port.

Field names are the spec's names (camelCase) in every tier, so cells, JSON and
docs agree without a mapping. The brain verifies only: phones and the issuer sign.
